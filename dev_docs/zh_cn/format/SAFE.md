## file

| 项目       | 当前规则                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------- |
| 脚本权限   | 仅游戏脚本可写，屏保脚本禁止；不要求开启调试模式                                          |
| 写入范围   | 限当前包的 `assets/`，解析后的路径必须仍在该目录内                                        |
| 路径格式   | 禁止绝对路径、`..`、空路径、NUL；路径最长 **8192 字节**                                   |
| 文件名     | 拒绝 Windows 保留设备名、非法字符，以及以空格或点结尾的路径段                             |
| 目标类型   | 父目录必须存在且为目录；允许创建新文件，禁止把目录当文件写入                              |
| 内容大小   | 输入最多 **1 MiB**；文本转换编码和换行后，输出仍不得超过 **1 MiB**                        |
| 文本模式   | 输入必须是有效 UTF-8、不能包含 NUL；过多异常控制字符会被判为二进制数据并拒绝              |
| 编码转换   | 不能无损编码时失败，不会静默替换无法表示的字符                                            |
| 二进制模式 | 允许任意字节，包括 NUL；忽略编码和换行参数                                                |
| 请求数量   | 每个 Session 最多 **8 个未完成文件请求**，读写等操作共用；共享宿主命令队列上限为 **4096** |

参数、路径或请求提交检查失败会同步抛出异常；提交后的磁盘权限不足、编码失败等，通过原有失败事件通知。实现见 [file.rs](E:/Code/tui-game/crates/service/lua/src/api/libraries/file.rs)。

写入采用“临时文件 → 同步磁盘 → 备份旧文件 → 替换”的流程，替换失败时尝试恢复旧文件，并清理临时文件。见 [atomic_fs (line 30)](/E:/Code/tui-game/crates/core/atomic_fs/src/lib.rs:30)。

目前还有几个实际边界：

- 允许覆盖已有文件，没有覆盖确认、扩展名白名单或累计磁盘用量配额。
- 没有同一文件的写入串行锁，多个异步请求同时写同一路径可能发生竞争。
- 路径检查与后台写入分开执行，尚不能完全防御外部程序在两者之间替换目录或链接的竞态。
- 备份恢复属于尽力处理，不能保证断电或进程被强制终止时一定完成恢复。

## animation

| 项目       | 当前实现                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| 对象数量   | 每个 Session 中，`animation`、`effect` **各最多 1024 个对象**，分别计数                                        |
| 对象归属   | 只能访问当前 Session 的对象                                                                                    |
| ID 检查    | 格式非法会报错；对象不存在时，除 `exists` 返回 `false`，其他需要 ID 的方法均报错                               |
| 生命周期   | `delete`／`clear` 释放对象；Session 停止或故障时统一释放                                                       |
| 自动回收   | 动画完成后仍保留对象并占用名额，需要手动删除                                                                   |
| 选项校验   | 拒绝未知选填参数、错误类型，以及带元表的选项表                                                                 |
| 时间参数   | `duration`、`delay`、`interval` 必须有限、非负且能转换为内部时间类型，允许 `0`；延迟或间隔加持续时间也不能溢出 |
| 循环次数   | `repeat` 为 **1～4294967295 的整数**或正无限，不接受 `false`                                                   |
| 关键帧数量 | 输入数组最多 **16384 项**                                                                                      |
| 参数规模   | 所有关键帧的 `values` 条目总数最多 **16384**；输入帧数 × 不同参数名数量也不得超过 **16384**                    |
| 时间点     | `timestamp` 必须处于 `[0, duration]`；乱序自动排序，重复时间点保留首项                                         |
| 插值配置   | 每张 `easing`／`callback_easing` 配置最多计入 **16384 项**；区段索引必须是正整数                               |
| 参数值     | 可以保存任意 Lua 值；连续插值要求值支持相应算术运算，否则在 `sample` 时报错                                    |
| 自定义缓动 | 执行错误会向外传播，并计入调用 `sample` 所在回调的执行预算                                                     |

此外，默认 Lua VM 内存上限为 32 MiB；常规回调执行预算为 20 万条指令／75 ms，加载、初始化和保存回调为 100 万条／100 ms。同一次着色器重放中的所有处理函数共用一份预算，并非每个字符重新获得额度。超限不能通过 debug.pcall 绕过，会使当前 Session 故障并释放对象。

这些数量上限也不代表可以无成本用满：着色面积、关键帧规模和自定义函数复杂度，可能先触及执行预算；32 MiB 也仅是 Lua VM 的内存限制，并非全部 Rust 侧数据的总内存上限。

## i18n

| 项目           | 限制                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------- |
| 实例数量       | 每个 Session 只有 **一个语言实例**                                                             |
| 并发加载       | 同一实例只能有一个创建／重载请求正在进行                                                       |
| 创建与重载     | 重复创建、尚未创建就重载、加载期间再次请求，均返回 `nil`                                       |
| 资源范围       | 加载当前包 `assets/language/<语言代码>/` 下的 JSON 文件，不递归加载子目录                      |
| 路径安全       | 必须通过沙箱检查；资源文件解析后不得越出对应语言目录                                           |
| 语言代码       | **1～64 字节**，仅允许 ASCII 字母、数字、`.`、`_`、`-`，还需通过路径检查                       |
| 命名空间文件名 | **1～128 字节**，仅允许上述字符                                                                |
| 文件格式       | 必须是有效 UTF-8 JSON，结构为**字符串键 → 字符串值**的扁平对象，不接受嵌套对象、数字、数组等值 |
| 资源数量       | 每种语言最多 **256 个命名空间文件**                                                            |
| 资源大小       | 单文件最多 **1 MiB**，每种语言合计最多 **4 MiB**；首选语言与回退语言分别计算                   |
| 查询名称       | `get_value` 的 `namespace`、`key` 各为 **1～512 字节**，禁止 NUL、回车、换行                   |
| 缺失处理       | 缺失语言资源可以完成加载并携带警告；缺失键返回指定回退文本或程序缺失提示                       |
| 重载失败       | 保留先前成功加载的数据；首次创建失败后允许重新创建                                             |

## math

I：integer 范围 [-9223372036854775808, 9223372036854775807]。
F：有限 float，约为 [-1.7976931348623157×10³⁰⁸, 1.7976931348623157×10³⁰⁸]，不包含 NaN、正负无限。
表中“有限数”表示接受 integer / float。
仅接受 integer 的参数会拒绝 2.0。
计算结果为 NaN 或正负无限时抛出异常；浮点下溢为 0 允许发生。

ldexp 的实际边界需要特别区分：

- x=0：允许任意 I 范围的 exp，直接返回带原符号的零。
- x≠0 且 exp>2097：报溢出异常。
- x≠0 且 exp<-2097：返回带 x 符号的零。
- -2097≤exp≤2097：仍取决于 x，计算结果溢出则报错。
  因此，当前文档里的“x 不得为 0、exp 只能在 [-2097,2097]”与实现并不一致。

另外，多数计算会将 integer 转为双精度浮点数，绝对值超过 2^53 的整数可能失去精度；这与是否越界是两回事。normalize_angle 的 integer 分支、整数取余和整数比较等保留整数运算。

| 方法                     | 数值限制及关系                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------- |
| `abs`                    | value 为有限数；返回绝对值                                                                                |
| `ceil`、`floor`、`round` | integer 输入接受完整 I；float 输入经对应取整后，结果必须落入 I                                            |
| `round_to`               | value 为有限数；precision 为 integer，范围 `[-308,308]`。正数表示小数位，负数表示整数位；舍入结果必须有限 |
| `fmod`                   | x、y 均为 I 中的 integer，`y≠0`；余数符号与 x 一致                                                        |
| `pow`                    | x、y 为有限数；计算 `x^y`。负底数的指数须为数值上的整数；`0` 的负次幂报错；`0^0=1`；结果必须有限          |
| `exp`                    | 计算 `e^value`；value 须有限，结果有限对应上限约 `709.782712893384`                                       |
| `log`                    | `value>0`；`base>0` 且 `base≠1`；两者均有限；计算 `ln(value)/ln(base)`                                    |
| `lg`、`ln`               | value 为有限正数，不能为 0                                                                                |
| `sqrt`                   | value 为有限数且 `value≥0`，允许 0                                                                        |
| `ldexp`                  | x 为有限数，exp 为 I 中的 integer；计算 `x×2^exp`，详细规则见下                                           |
| `frexp`                  | value 为有限数；满足 `value=mantissa×2^exponent`。非零时 `0.5≤abs(mantissa)<1`；零返回零尾数和零指数      |
| `sin`、`cos`、`tan`      | value 为有限数，单位为弧度；按浮点三角函数计算，没有额外的周期范围限制                                    |
| `asin`、`acos`           | `-1≤value≤1`                                                                                              |
| `atan`                   | value 为有限数                                                                                            |
| `atan2`                  | y、x 均为有限数，允许两者同时为 0；返回角度范围 `[-π,π]`                                                  |
| `deg`                    | value 为有限弧度；计算 `value×180/π`，结果必须有限                                                        |
| `rad`                    | value 为有限角度；计算 `value×π/180`                                                                      |
| `normalize_angle`        | value 为有限数；返回 `[0,360)` 内的角度                                                                   |
| `max`、`min`             | 接受长度 `[1,16384]` 的稠密数组，元素均为有限数；若提供 n，必须为相同范围的 integer，并与数组结构一致     |
| `modf`                   | integer 输入接受完整 I；float 的截断整数部分必须落入 I。返回整数部分和小数部分，二者之和对应原值          |
| `ult`                    | left、right 均为 I 中的 integer；按无符号 64 位整数比较，负数按原二进制位解释                             |
| `approx_equal`           | left、right 为有限数；epsilon 为有限非负数，默认 `1e-10`；判断 `left==right` 或 `abs(left-right)≤epsilon` |
| `ratio`                  | value、total 为有限数，`total≠0`；默认计算 `value/total`，as_percent=true 再乘 100；结果必须有限          |
| `factorial`              | n 为 integer，`0≤n≤170`；返回浮点阶乘，`0!=1`                                                             |
| `combination`            | n、k 为 integer，满足 `0≤k≤n≤I上限`；结果 `C(n,k)` 必须不超过 I 上限                                      |
| `tointeger`              | 接受任意类型；integer 原样返回，float 必须有限、无小数部分且处于 `[-2^63,2^63)`，否则返回 nil             |
| `type`                   | 接受任意类型；integer 返回 `"integer"`，float（包括 NaN、无限）返回 `"float"`，其他返回 nil               |
