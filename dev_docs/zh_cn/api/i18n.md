# i18n 库

`i18n` 用来异步加载语言资源，并按命名空间和键名读取翻译文本。

---

# 目录

## 方法

| 方法 | 说明 | 定位 |
| --- | --- | --- |
| `create` | 创建语言实例 | [create](#create) |
| `get_value` | 查询翻译文本 | [get_value](#get_value) |
| `get_language_code` | 查询当前语言代码 | [get_language_code](#get_language_code) |
| `reload` | 重新加载语言资源 | [reload](#reload) |

# 方法

## `create`

请求创建语言实例。任务入队后立即返回 request id；结果通过 `i18n` 事件送回。

### 调用

```lua
i18n.create
```

## 参数

### 选填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `language_code` | string | 首选语言代码；省略时采用系统语言。 |
| `callback_language_code` | string | 回退语言代码；缺少首选语言内容时使用，默认 `"en_us"`。 |

## 返回值

成功入队时返回当前会话内的整数 request id。已有实例或请求被去重时返回一个 nil；未入队的请求不会产生终态事件。

| 类型 | 说明 |
| --- | --- |
| integer / nil | 新请求的 ID，或未入队时的 nil。 |

### 示例

```lua
local request_id = i18n.create({language_code = "zh_cn"})

function HandleEvent(event)
  if event.type == "i18n" and event.data.request_id == request_id then
    debug.print(event.data.kind)
  end
end
```

**输出：**

```lua
```

### 额外说明

- 每个脚本环境只有一个语言实例。
- 首选语言目录或 JSON 缺失时按空语言处理，仍会加载成功；回退语言同样处理。两种语言都缺失时也能成功创建。
- 完成事件的 ok 为 true；缺少语言资源时 warning 是提示文字，会指出首选语言或回退语言及对应代码，无警告时为 nil。缺少某个键不会单独产生加载警告。
- language_code 保持请求指定的首选语言代码，不会因为使用回退文本而改成回退语言代码。
- JSON 格式错误、读取失败、资源超限或不安全路径仍会导致加载失败；失败通过事件通知。查看⌞[i18n 事件](../EVENT.md#55-i18n)⌝。
- 资源目录结构见⌞[国际化语言](../format/I18N.md)⌝。

## `get_value`

按命名空间和键名查询翻译文本。未找到的内容按语言资源规则回退。

### 调用

```lua
i18n.get_value
```

## 参数

### 必填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `namespace` | string | 语言资源命名空间。 |
| `key` | string | 要查询的键名。 |

### 选填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `callback` | string | 默认：程序的缺失键提示；两种语言都找不到该键时返回的备用文字。 |

## 返回值

返回翻译文本字符串。

| 类型 | 说明 |
| --- | --- |
| string | 找到的翻译文本或按资源规则回退的文本。 |

### 示例

```lua
local title = i18n.get_value("menu", "title", {callback = "游戏标题"})
debug.print(title)
```

**输出：**

```lua
```

### 额外说明

- 必填参数按顺序传入，选填参数放在末尾严格表中，例如 `i18n.get_value("menu", "title", {callback = "游戏标题"})`。未知字段或非字符串 callback 会报错。
- 按首选语言、回退语言、callback 的顺序查找；callback 仅在两种语言都没有该键时使用。已有翻译即使是空字符串，也不会使用 callback。
- callback 可以是空字符串，按填写的内容原样返回，不替换其中的占位符。省略或写 nil 时使用程序的缺失键提示。
- 请先调用 create 并等待加载完成事件，再查询资源；尚未加载时同样可以使用 callback 作为备用文字。

- 翻译文件的目录和键格式见⌞[国际化语言](../format/I18N.md)⌝。

## `get_language_code`

获取程序当前使用的语言代码。

### 调用

```lua
i18n.get_language_code
```

## 返回值

返回语言代码字符串。

| 类型 | 说明 |
| --- | --- |
| string | 程序当前语言代码，不代表本次 `create` 或 `reload` 请求指定的首选语言。 |

### 示例

```lua
debug.print(i18n.get_language_code())
```


## `reload`

请求重新加载现有语言实例。任务入队后立即返回 request id；结果通过 `i18n` 事件送回。

### 调用

```lua
i18n.reload
```

## 参数

### 选填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `language_code` | string | 首选语言代码；省略时采用系统语言。 |
| `callback_language_code` | string | 回退语言代码；缺少首选语言内容时使用，默认 `"en_us"`。 |

## 返回值

成功入队时返回当前会话内的整数 request id。请求被去重时返回一个 nil；实例未创建时会报错。

| 类型 | 说明 |
| --- | --- |
| integer / nil | 新请求的 ID，或未入队时的 nil。 |

### 示例

```lua
local create_id = i18n.create({language_code = "zh_cn"})
local request_id = nil

function HandleEvent(event)
  if event.type ~= "i18n" then return end
  if event.data.request_id == create_id and event.data.kind == "created" and event.data.ok then
    request_id = i18n.reload({language_code = "zh_cn"})
  elseif event.data.request_id == request_id then
    debug.print(event.data.kind)
  end
end
```

**输出：**

```lua
```

### 额外说明

- 缺少首选语言或回退语言目录、JSON 时仍加载成功，完成事件的 ok 为 true，warning 会说明缺少哪种语言。
- 重载成功会替换旧数据；两种语言都缺失时会清空旧翻译，不会继续使用上一次的文本。
- JSON 格式错误、读取失败等真正的加载错误仍返回 ok 为 false，并保留上一次成功加载的数据。
- 首选语言代码保持请求值；资源与警告规则与 create 一致。查看⌞[create](#create)⌝。
