# i18n 库

`i18n` 用来异步加载语言资源，并按命名空间和键名读取翻译文本。

---

# 目录

## 方法

| 方法                | 说明                         | 定位                                    |
| ------------------- | ---------------------------- | --------------------------------------- |
| `create`            | 请求创建语言实例             | [create](#create)                       |
| `get_value`         | 按命名空间和键名查询翻译文本 | [get_value](#get_value)                 |
| `get_language_code` | 获取程序当前使用的语言代码   | [get_language_code](#get_language_code) |
| `reload`            | 请求重新加载现有语言实例     | [reload](#reload)                       |

---

# 方法

## `create`

请求创建语言实例。

### 调用

```lua
i18n.create
```

## 参数

### 选填参数

| 参数名                   | 类型   | 默认值           | 说明         |
| ------------------------ | ------ | ---------------- | ------------ |
| `language_code`          | string | 程序当前语言代码 | 首选语言代码 |
| `callback_language_code` | string | `"en_us"`        | 回退语言代码 |

## 返回值

**请求提交成功时**，返回一个值。

| 类型   | 说明    |
| ------ | ------- |
| string | 事件 ID |

**请求提交失败时**，返回一个值。

| 类型 | 说明         |
| ---- | ------------ |
| nil  | 请求提交失败 |

### 示例

```lua
local request_id = i18n.create()

function HandleEvent(event)
  if event.type == "i18n" then
    debug.print(table.pretty(event))
  end
end
```

**输出：**

```lua
{
  type = "i18n",
  frame = X,        -- 占位符
  sequence = X,     -- 占位符
  data = {
    request_id = X, -- 占位符
    kind = "created",
    ok = true,
    message = "i18n instance created",
    language_code = "zh_cn",
    callback_language_code = "en_us"
  }
}
```

## 额外说明

- 每个会话只有一个语言实例。
- 事件返回值见⌊[事件协议](../EVENT.md)⌉
- 资源目录结构见⌊[国际化语言](../format/I18N.md)⌉。

## `get_value`

按命名空间和键名查询翻译文本。

### 调用

```lua
i18n.get_value
```

## 参数

### 必填参数

| 参数名      | 类型   | 说明             |
| ----------- | ------ | ---------------- |
| `namespace` | string | 语言资源命名空间 |
| `key`       | string | 要查询的键名     |

### 选填参数

| 参数名     | 类型   | 默认值           | 说明                 |
| ---------- | ------ | ---------------- | -------------------- |
| `callback` | string | 程序的缺失键提示 | 查询失败后的回退文本 |

## 返回值

返回一个值。

| 类型   | 说明               |
| ------ | ------------------ |
| string | 查询到或回退的文本 |

### 示例

```lua
local title = i18n.get_value("menu", "title", {callback = "Menu"})
debug.print(title)
```

**输出：**

```lua
Menu
```

## `get_language_code`

获取程序当前使用的语言代码。

### 调用

```lua
i18n.get_language_code
```

## 返回值

返回语言代码字符串。

| 类型   | 说明             |
| ------ | ---------------- |
| string | 程序当前语言代码 |

### 示例

```lua
debug.print(i18n.get_language_code())
```

**输出：**

```lua
zh_cn
```

## `reload`

请求重新加载现有语言实例。

### 调用

```lua
i18n.reload
```

## 参数

### 选填参数

| 参数名                   | 类型   | 默认值           | 说明                                 |
| ------------------------ | ------ | ---------------- | ------------------------------------ |
| `language_code`          | string | 程序当前语言代码 | 首选语言代码                         |
| `callback_language_code` | string | `"en_us"`        | 回退语言代码；缺少首选语言内容时使用 |

## 返回值

**请求提交成功时**，返回一个值。

| 类型   | 说明    |
| ------ | ------- |
| string | 事件 ID |

**请求提交失败时**，返回一个值。

| 类型 | 说明         |
| ---- | ------------ |
| nil  | 请求提交失败 |

### 示例

```lua
local request_id = i18n.create()

function HandleEvent(event)
  if event.type == "i18n" then
    if event.data.kind == "reloaded" then
      debug.print(table.pretty(event))
    else
      request_id = i18n.reload()
    end
  end
end
```

**输出：**

```lua
{
  type = "i18n",
  frame = X,        -- 占位符
  sequence = X,     -- 占位符
  data = {
    request_id = X, -- 占位符
    kind = "reloaded",
    ok = true,
    message = "i18n instance reloaded",
    language_code = "zh_cn",
    callback_language_code = "en_us"
  }
}
```

## 额外说明

- 事件返回值见⌊[事件协议](../EVENT.md)⌉
