# i18n 库

`i18n` 用来异步加载语言资源，并按命名空间和键名读取翻译文本。

---

# 目录

## 方法

| 方法 | 说明 | 定位 |
| --- | --- | --- |
| `create` | 创建语言实例 | [create](#create) |
| `get_value` | 查询翻译文本 | [get_value](#get_value) |
| `get_language_code` | 查询当前语言代码 | [get_language_code](#get_language_code) |
| `reload` | 重新加载语言资源 | [reload](#reload) |

---

# 方法

## `create`

请求创建语言实例。任务入队后立即返回 request id；结果通过 `i18n` 事件送回。

### 调用

```lua
i18n.create
```

## 参数

### 选填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `language_code` | string | 首选语言代码；省略时采用系统语言。 |
| `callback_language_code` | string | 回退语言代码；缺少首选语言内容时使用，默认 `"en_us"`。 |

## 返回值

成功入队时返回当前会话内的整数 request id。已有实例或请求被去重时返回一个 nil；未入队的请求不会产生终态事件。

| 类型 | 说明 |
| --- | --- |
| integer / nil | 新请求的 ID，或未入队时的 nil。 |

### 示例

```lua
local request_id = i18n.create({language_code = "zh_cn"})

function HandleEvent(event)
  if event.type == "i18n" and event.data.request_id == request_id then
    debug.print(event.data.kind)
  end
end
```

**输出：**

```lua
```

### 额外说明

- 每个脚本环境只有一个语言实例。
- 资源目录结构见⌞[国际化语言](../format/I18N.md)⌝。

## `get_value`

按命名空间和键名查询翻译文本。未找到的内容按语言资源规则回退。

### 调用

```lua
i18n.get_value
```

## 参数

### 必填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `namespace` | string | 语言资源命名空间。 |
| `key` | string | 要查询的键名。 |

## 返回值

返回翻译文本字符串。

| 类型 | 说明 |
| --- | --- |
| string | 找到的翻译文本或按资源规则回退的文本。 |

### 示例

```lua
local title = i18n.get_value("menu", "title")
debug.print(title)
```

**输出：**

```lua
```

### 额外说明

- 请先调用 `i18n.create` 并等待加载完成事件，再查询实际资源；尚未加载或找不到键时返回缺失提示文本。

- 翻译文件的目录和键格式见⌞[国际化语言](../format/I18N.md)⌝。

## `reload`

请求重新加载现有语言实例。任务入队后立即返回 request id；结果通过 `i18n` 事件送回。

### 调用

```lua
i18n.reload
```

## 参数

### 选填参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `language_code` | string | 首选语言代码；省略时采用系统语言。 |
| `callback_language_code` | string | 回退语言代码；缺少首选语言内容时使用，默认 `"en_us"`。 |

## 返回值

成功入队时返回当前会话内的整数 request id。请求被去重时返回一个 nil；实例未创建时会报错。

| 类型 | 说明 |
| --- | --- |
| integer / nil | 新请求的 ID，或未入队时的 nil。 |

### 示例

```lua
local create_id = i18n.create({language_code = "zh_cn"})
local request_id = nil

function HandleEvent(event)
  if event.type ~= "i18n" then return end
  if event.data.request_id == create_id and event.data.kind == "created" and event.data.ok then
    request_id = i18n.reload({language_code = "zh_cn"})
  elseif event.data.request_id == request_id then
    debug.print(event.data.kind)
  end
end
```
