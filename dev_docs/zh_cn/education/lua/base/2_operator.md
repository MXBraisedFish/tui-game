# Lua 运算符

> 该教程文档使用的是原生 Lua 语言，语法本身完全合规，但 Tui Game 程序并非原生 Lua 运行器，因此无法直接运行该文档中的代码。

---

## 总览

Lua 中有以下六类运算符。

| 类别   | 运算符                       |
| ------ | ---------------------------- |
| 算术   | `+` `-` `*` `/` `//` `%` `^` |
| 关系   | `==` `~=` `<` `>` `<=` `>=`  |
| 逻辑   | `and` `or` `not`             |
| 拼接   | `..`                         |
| 长度   | `#`                          |
| 位运算 | `&` `\|` `~` `<<` `>>`       |

---

## 算术运算符

最基本的数学运算符。

| 运算符 | 作用           |
| ------ | -------------- |
| `+`    | 加法           |
| `-`    | 减法           |
| `*`    | 乘法           |
| `/`    | 除法           |
| `//`   | 向下取整除法   |
| `%`    | 取模（求余数） |
| `^`    | 幂运算         |

### 示例

```lua
print(3 + 2)
print(3 - 2)
print(3 * 2)
print(3 / 2)
print(3 // 2)
print(3 % 2)
print(3 ^ 2)
```

输出：

```text
5
1
6
1.5
1
1
9.0
```

### 额外补充

- `^`、`/` 返回值一定为浮点数。
- `//` 返回值符号与被除数（右操作数）相同。

---

## 关系运算符

最基本的数据关系运算。

| 运算符 | 作用     |
| ------ | -------- |
| `==`   | 等于     |
| `~=`   | 不等于   |
| `<`    | 小于     |
| `>`    | 大于     |
| `<=`   | 小于等于 |
| `>=`   | 大于等于 |

### 示例

```lua
print(1 == 1)
print(1 ~= 2)
print(1 < 0)
print(2 > 1)
print(1 <= 1)
print(2 >= 5)
```

输出：

```lua
true
true
false
true
true
false
```

### 额外补充

- `==` 和 `~=` 可以比较任何数据类型。
- `<`、`>`、`<=`、`>=` 只能用于两个数值和两个字符串之间比较。

---

## 逻辑运算符

最基本的逻辑运算符。

| 运算符 | 作用   |
| ------ | ------ |
| `and`  | 逻辑与 |
| `or`   | 逻辑或 |
| `not`  | 逻辑非 |

### 示例

```lua
print(true and false)
print(true or false)
print(not true)
```

输出：

```text
false
true
false
```

### 额外补充

- `and` 和 `or` 并非返回布尔值，而是采用**短路**求值。

```text
and 的短路：
  左边为假 → 整个表达式必为假 → 直接返回左边，不计算右边
  左边为真 → 结果取决于右边 → 继续计算并返回右边

or 的短路：
  左边为真 → 整个表达式必为真 → 直接返回左边，不计算右边
  左边为假 → 结果取决于右边 → 继续计算并返回右边
```

- `not` 一定返回布尔值。

## 拼接运算符

专门用于字符串拼接。

| 运算符 | 作用       |
| ------ | ---------- |
| `..`   | 字符串拼接 |

### 示例

```lua
print("Hello" .. " " .. "World")
print("Number: " .. 42)
print(1 .. 2)
print("Float: " .. 3.8)
```

输出：

```text
171 ms
Hello World
Number: 42
12
Float: 3.8

```

### 额外补充：

- 该运算符只能拼接数字或字符串。
- 数字会按照类型精准转换为字符串（即保留小数位）。

---

## 长度运算符

基本的长度运算符。

| 运算符 | 作用   |
| ------ | ------ |
| `#`    | 取长度 |

### 示例

```lua
print(#"hello")
print(#{1, 2, 3})
```

输出：

```text
5
3
```

### 注意事项：

- 该运算符对字符串返回字节数，不是字符数。
- 该运算符对 table 返回的是"边界"，不是元素个数。
- 该运算符只能计算表或字符串。

---

## 位运算符

基本的位运算符。

| 运算符 | 作用                               |
| ------ | ---------------------------------- |
| `&`    | 按位与                             |
| `\|`   | 按位或                             |
| `~`    | 按位异或（二元）；按位取反（一元） |
| `<<`   | 左移                               |
| `>>`   | 右移                               |

### 示例

```lua
print(6 & 3)
print(6 | 3)
print(6 ~ 3)
print(~6)
print(1 << 4)
print(16 >> 2)
```

输出：

```text
2
7
5
-7
16
4
```

### 额外补充

- 操作数必须是整数。
- 位宽固定为 64 位有符号整数。
- `~` 具有一元和二元不同操作（即一个操作数和两个操作数）。
- `<<` 和 `>>` 移位量先对 64 取模再移位，负数移位量表示反方向移位。
- `<<` 不保留符号。
- `>>` 为逻辑右移，即不保留符号，向左补 0。

## 运算符优先级

表格越靠上的运算符优先级越高。

| 优先级 | 运算符                      |
| ------ | --------------------------- |
| 1      | `^`                         |
| 2      | `not` `#` `~`（一元取反）   |
| 3      | `*` `/` `//` `%`            |
| 4      | `+` `-`                     |
| 5      | `..`                        |
| 6      | `<<` `>>`                   |
| 7      | `&`                         |
| 8      | `~`（二元异或）             |
| 9      | `\|`                        |
| 10     | `==` `~=` `<` `>` `<=` `>=` |
| 11     | `and`                       |
| 12     | `or`                        |

## 同级运算符计算方向

### 从左往右（左结合）

| 运算符                      | 结合性 |
| --------------------------- | ------ |
| `+` `-`                     | 左结合 |
| `*` `/` `//` `%`            | 左结合 |
| `<<` `>>`                   | 左结合 |
| `&`                         | 左结合 |
| `~`（二元异或）             | 左结合 |
| `\|`                        | 左结合 |
| `==` `~=` `<` `>` `<=` `>=` | 左结合 |
| `and`                       | 左结合 |
| `or`                        | 左结合 |

### 从右往左（右结合）

| 运算符 | 结合性 |
| ------ | ------ |
| `..`   | 右结合 |
| `^`    | 右结合 |
