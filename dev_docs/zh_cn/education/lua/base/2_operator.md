# Lua 运算符

> 该教程文档使用的是原生 Lua 语言，语法本身完全合规，但 Tui Game 程序并非原生 Lua 运行器，因此无法直接运行该文档中的代码。

---

Lua 有六类运算符：

| 类别   | 运算符                       |
| ------ | ---------------------------- |
| 算术   | `+` `-` `*` `/` `//` `%` `^` |
| 关系   | `==` `~=` `<` `>` `<=` `>=`  |
| 逻辑   | `and` `or` `not`             |
| 拼接   | `..`                         |
| 长度   | `#`                          |
| 位运算 | `&` `\|` `~` `<<` `>>`       |

---

## 算术运算符

| 运算符 | 作用           |
| ------ | -------------- |
| `+`    | 加法           |
| `-`    | 减法           |
| `*`    | 乘法           |
| `/`    | 除法           |
| `//`   | 向下取整除法   |
| `%`    | 取模（求余数） |
| `^`    | 幂运算         |

```lua
print(3 + 2)   -- 5
print(3 - 2)   -- 1
print(3 * 2)   -- 6
print(3 / 2)   -- 1.5
print(3 // 2)  -- 1
print(3 % 2)   -- 1
print(3 ^ 2)   -- 9.0
```

- `^`、`/` 返回值一定为浮点数。
- `//` 返回值符号与被除数（右操作数）相同。

---

## 关系运算符

| 运算符 | 作用     |
| ------ | -------- |
| `==`   | 等于     |
| `~=`   | 不等于   |
| `<`    | 小于     |
| `>`    | 大于     |
| `<=`   | 小于等于 |
| `>=`   | 大于等于 |

```lua
print(1 == 1)  -- true
print(1 ~= 2)  -- true
print(1 < 0)   -- false
print(2 > 1)   -- true
print(1 <= 1)  -- true
print(2 >= 5)  -- false
```

- `==` 和 `~=` 可比较任何数据类型。
- `<`、`>`、`<=`、`>=` 只能用于两个数值或两个字符串之间比较。

---

## 逻辑运算符

| 运算符 | 作用   |
| ------ | ------ |
| `and`  | 逻辑与 |
| `or`   | 逻辑或 |
| `not`  | 逻辑非 |

```lua
print(true and false)  -- false
print(true or false)   -- true
print(not true)        -- false
```

- `and` 和 `or` 采用**短路**求值，并不返回布尔值：

```text
and：左边为假 → 返回左边，不计算右边
     左边为真 → 返回右边

or： 左边为真 → 返回左边，不计算右边
     左边为假 → 返回右边
```

- `not` 一定返回布尔值。

---

## 拼接运算符

| 运算符 | 作用       |
| ------ | ---------- |
| `..`   | 字符串拼接 |

```lua
print("Hello" .. " " .. "World")  -- Hello World
print("Number: " .. 42)           -- Number: 42
print(1 .. 2)                     -- 12
print("Float: " .. 3.8)           -- Float: 3.8
```

- 只能拼接数字和字符串。
- 数字按其类型精确转换为字符串（保留小数位）。
- 拼接数字时，运算符两侧必须用空格分隔，写作 `x .. y`。

---

## 长度运算符

| 运算符 | 作用   |
| ------ | ------ |
| `#`    | 取长度 |

```lua
print(#"hello")    -- 5
print(#{1, 2, 3})  -- 3
```

- 对字符串返回字节数，而非字符数。
- 对 table 返回的是“边界”，而非元素个数；表中存在数据空洞时，返回值不可预测。
- 只能用于表或字符串。

---

## 位运算符

| 运算符 | 作用                               |
| ------ | ---------------------------------- |
| `&`    | 按位与                             |
| `\|`   | 按位或                             |
| `~`    | 按位异或（二元）；按位取反（一元） |
| `<<`   | 左移                               |
| `>>`   | 右移                               |

```lua
print(6 & 3)    -- 2
print(6 | 3)    -- 7
print(6 ~ 3)    -- 5
print(~6)       -- -7
print(1 << 4)   -- 16
print(16 >> 2)  -- 4
```

- 操作数必须是整数。
- 位宽固定为 64 位有符号整数。
- `~` 具有一元和二元两种操作。
- `<<` 和 `>>` 移位量先对 64 取模再移位，负数移位量表示反方向移位。
- `<<` 不保留符号。
- `>>` 为逻辑右移，不保留符号，向左补 0。

---

## 运算符优先级

表格越靠上优先级越高，可用 `()` 结合运算符。

| 优先级 | 运算符                      |
| ------ | --------------------------- |
| 1      | `^`                         |
| 2      | `not` `#` `~`（一元取反）   |
| 3      | `*` `/` `//` `%`            |
| 4      | `+` `-`                     |
| 5      | `..`                        |
| 6      | `<<` `>>`                   |
| 7      | `&`                         |
| 8      | `~`（二元异或）             |
| 9      | `\|`                        |
| 10     | `==` `~=` `<` `>` `<=` `>=` |
| 11     | `and`                       |
| 12     | `or`                        |

---

## 同级运算符计算方向

**从左往右（左结合）：**

| 运算符                      | 结合性 |
| --------------------------- | ------ |
| `+` `-`                     | 左结合 |
| `*` `/` `//` `%`            | 左结合 |
| `<<` `>>`                   | 左结合 |
| `&`                         | 左结合 |
| `~`（二元异或）             | 左结合 |
| `\|`                        | 左结合 |
| `==` `~=` `<` `>` `<=` `>=` | 左结合 |
| `and`                       | 左结合 |
| `or`                        | 左结合 |

**从右往左（右结合）：**

| 运算符 | 结合性 |
| ------ | ------ |
| `..`   | 右结合 |
| `^`    | 右结合 |
