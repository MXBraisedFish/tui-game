# Lua 运算符

Lua 的运算符分为几大类：算术、关系、逻辑、拼接、长度、位运算等。

> 该教程文档使用的是原生 Lua 语言，语法本身完全合规，但 Tui Game 程序并非原生 Lua 运行器，因此无法直接运行该文档中的代码。

---

## 总览

| 类别   | 运算符                       |
| ------ | ---------------------------- |
| 算术   | `+` `-` `*` `/` `//` `%` `^` |
| 关系   | `==` `~=` `<` `>` `<=` `>=`  |
| 逻辑   | `and` `or` `not`             |
| 拼接   | `..`                         |
| 长度   | `#`                          |
| 位运算 | `&` `\|` `~` `<<` `>>`       |

## 1. 算术运算符

| 运算符 | 作用             |
| ------ | ---------------- |
| `+`    | 加法             |
| `-`    | 减法             |
| `*`    | 乘法             |
| `/`    | 除法（浮点除法） |
| `//`   | 向下取整除法     |
| `%`    | 取模（求余数）   |
| `^`    | 幂运算（乘方）   |

```lua
print(7 + 3)    -- 10
print(7 - 3)    -- 4
print(7 * 3)    -- 21
print(7 / 3)    -- 2.333...（除法总返回浮点）
print(7 // 3)   -- 2（整除，向下取整）
print(7 % 3)    -- 1（取模）
print(2 ^ 10)   -- 1024.0（幂运算，返回浮点）
print(-5)       -- -5（一元负号）
```

**取模 `%` 的特殊之处**：结果符号跟随除数（第二个操作数），而非被除数。

```lua
print(7 % 3)     --  1
print(-7 % 3)    --  2   （不是 -1）
print(7 % -3)    -- -2
print(-7 % -3)   -- -1
```

**整除 `//`** 也是向下取整：

```lua
print(7 // 2)     --  3
print(-7 // 2)    -- -4  （向下取整，不是 -3）
```

**字符串自动转数字**：

```lua
print("10" + 5)   -- 15
print("3" * "4")  -- 12
```

注意：`+` 不会拼接字符串，拼接要用 `..`。`"10" + 5` 是数字运算，`10 .. 5` 才是字符串拼接。

## 2. 关系运算符

| 运算符 | 作用     |
| ------ | -------- |
| `==`   | 等于     |
| `~=`   | 不等于   |
| `<`    | 小于     |
| `>`    | 大于     |
| `<=`   | 小于等于 |
| `>=`   | 大于等于 |

结果总是 `boolean`（`true`/`false`）。

```lua
print(1 == 1)      -- true
print(1 ~= 2)      -- true（~= 是不等于，不是 !=）
print(3 < 5)       -- true
print(3 > 5)       -- false
print(3 <= 3)      -- true
print(3 >= 4)      -- false
```

**比较规则**：

- **数字**按数值比较。
- **字符串**按字典序（逐字节）比较。
- **不同类型**之间，`==` 返回 `false`，`~=` 返回 `true`（不会报错）。
- **大小比较**（`<` `>`）只能在**同类型**（都是数字或都是字符串）之间进行，否则报错。

```lua
print(1 == "1")    -- false（类型不同）
print(1 ~= "1")    -- true
print("abc" < "abd")  -- true（字典序）
-- print(1 < "2")   -- 报错：attempt to compare number with string
```

**table、function 等按引用比较**：

```lua
local a = {1}
local b = {1}
local c = a
print(a == b)   -- false（不同对象）
print(a == c)   -- true （同一引用）
```

> 注意：整数和浮点数只要数值相等就相等：`1 == 1.0` 为 `true`。

## 3. 逻辑运算符

| 运算符 | 作用   |
| ------ | ------ |
| `and`  | 逻辑与 |
| `or`   | 逻辑或 |
| `not`  | 逻辑非 |

**关键特性：返回值不一定是布尔值**，采用"短路求值"。

### 短路规则

- `a and b`：若 `a` 为假（`nil`/`false`），返回 `a`；否则返回 `b`。
- `a or b`：若 `a` 为真，返回 `a`；否则返回 `b`。
- `not a`：总是返回 `true` 或 `false`。

```lua
print(nil and 10)    -- nil
print(false and 10)  -- false
print(1 and 10)      -- 10
print(0 and 10)      -- 10（0 为真！）

print(nil or 10)     -- 10
print(false or 10)   -- 10
print(1 or 10)       -- 1

print(not nil)       -- true
print(not 0)         -- false（0 为真）
print(not "")        -- false
```

### 常用技巧

```lua
-- 设置默认值
local function greet(name)
  name = name or "world"
  print("Hello, " .. name)
end

-- 条件赋值
local config = config or {}

-- 模拟三元表达式：(条件) and 真值 or 假值
local x = 5
local msg = (x > 0) and "正数" or "非正数"
print(msg)   -- 正数
```

注意：三元表达式陷阱，如果"真值"本身是 `false` 或 `nil`，会错误地返回"假值"。此时应改用 `if`。

```lua
-- 想表达：x 为真则返回 false，否则返回 true，但结果错误
local y = (x) and false or "默认"   -- 结果总是 "默认"
```

## 4. 拼接运算符 `..`

| 运算符 | 作用       |
| ------ | ---------- |
| `..`   | 字符串拼接 |

把字符串（或数字）连接起来，结果是字符串。

```lua
print("Hello" .. " " .. "World")  -- Hello World
print("数字: " .. 42)              -- 数字: 42（数字自动转字符串）
print(1 .. 2)                      -- 12（注意：数字参与拼接会转字符串）
```

注意：空格陷阱，`1 .. 2` 中间必须有空格，否则 `1..2` 会被解析成 `1.` 和 `.2`（两个数字）。

---

## 5. 长度运算符 `#`

| 运算符 | 作用                       |
| ------ | -------------------------- |
| `#`    | 取长度（字符串或表的长度） |

返回字符串的字节数或 table 的数组长度。

```lua
print(#"hello")        -- 5
print(#{10, 20, 30})   -- 3
print(#"中文")          -- 6（UTF-8 每个汉字 3 字节）
```

> table 的 `#` 只对**连续数组部分**有意义，遇到 `nil` 会不确定。字典部分不计数。

```lua
local t = {1, 2, nil, 4}
print(#t)   -- 可能是 2 或 4，结果未定义，应避免这种结构
```

## 6. 位运算符

| 运算符 | 作用                               |
| ------ | ---------------------------------- |
| `&`    | 按位与                             |
| `\|`   | 按位或                             |
| `~`    | 按位异或（二元）；按位取反（一元） |
| `<<`   | 左移                               |
| `>>`   | 右移                               |

对整数按位操作。

```lua
print(5 & 3)     -- 1   （按位与）
print(5 | 3)     -- 7   （按位或）
print(5 ~ 3)     -- 6   （按位异或，注意 ~ 不是取反）
print(~5)        -- -6  （按位取反，一元）
print(1 << 4)    -- 16  （左移）
print(16 >> 2)   -- 4   （右移）
```

> 注意：`~` 是一元取反/二元异或，而 `~=` 是不等于，别混淆。

---

## 7. 运算符优先级

从高到低（同级的通常左结合）：

```
^                         -- 右结合
not  #  -（一元）  ~（一元）
*  /  //  %
+  -
..                        -- 右结合
<<  >>
&
~（二元异或）
|
<  >  <=  >=  ~=  ==
and
or
```

**易错点**：`..` 优先级低于 `+`，且是右结合。

```lua
print(1 + 2 .. "x")   -- "3x"（先算 1+2，再拼接）
print("a" .. "b" .. "c")  -- "abc"（右结合：a..(b..c)）
```

**建议**：不确定时用括号明确，代码更清晰。

```lua
print((1 + 2) * 3)   -- 9
print(1 + 2 * 3)     -- 7
```
