## Lua 简介

Lua 于 1993 年由巴西里约热内卢天主教大学（PUC-Rio）团队开发，名字在葡萄牙语中意为“月亮”。

Lua 以轻量、可嵌入、易扩展为设计目标，采用 ANSI C 实现并以 MIT 许可证发布，具备体积小、速度快、可嵌入、动态类型、自动内存管理、多范式及原生协程等特点。

总体而言，Lua 的优点是轻量、快、易嵌入、语法简单、社区成熟、许可证宽松；缺点是标准库较小（许多功能依赖 C 扩展或第三方库）、没有内置的类与异常机制、调试工具相对不如大型语言丰富。
