## Lua 关键字

> 该教程文档使用的是原生 Lua 语言，语法本身完全合规，但 Tui Game 程序并非原生 Lua 运行器，因此无法直接运行该文档中的代码。

---

Lua 共有 **22 个**关键字。

| 关键字     | 类别     | 作用                             |
| ---------- | -------- | -------------------------------- |
| `and`      | 逻辑     | 逻辑与，短路求值                 |
| `or`       | 逻辑     | 逻辑或，短路求值                 |
| `not`      | 逻辑     | 逻辑非，一定返回布尔值           |
| `nil`      | 值       | 空值，唯一空类型                 |
| `true`     | 值       | 布尔真                           |
| `false`    | 值       | 布尔假                           |
| `if`       | 条件分支 | 条件判断起始                     |
| `then`     | 条件分支 | 条件为真时执行的代码块起始       |
| `elseif`   | 条件分支 | 追加条件判断                     |
| `else`     | 条件分支 | 所有条件不满足时的分支           |
| `end`      | 结构     | 结束代码块                       |
| `while`    | 循环     | 先判断再执行                     |
| `do`       | 循环     | 循环体或代码块起始               |
| `repeat`   | 循环     | 先执行再判断                     |
| `until`    | 循环     | repeat 循环的条件判断            |
| `for`      | 循环     | 数值 for 或泛型 for              |
| `in`       | 循环     | 泛型 for 中引入迭代器            |
| `break`    | 跳转     | 提前跳出当前循环                 |
| `goto`     | 跳转     | 跳转到标签                       |
| `function` | 函数     | 定义函数                         |
| `return`   | 函数     | 返回结果，只能写在代码块最后     |
| `local`    | 变量     | 声明局部变量                     |

---

### 分类速记

- **逻辑**：`and` `or` `not`
- **值**：`nil` `true` `false`
- **条件分支**：`if` `then` `elseif` `else`
- **循环**：`while` `do` `repeat` `until` `for` `in`
- **跳转**：`break` `goto`
- **函数**：`function` `return`
- **变量**：`local`
- **结构**：`end`

---

### 额外补充

- 关键字不能用作标识符（变量名、函数名等）。
- `end` 是使用最多的关键字之一，用于结束 `if`、`while`、`for`、`function` 等代码块。
- Lua 区分大小写，`Nil`、`True`、`Function` 等都不是关键字，可作标识符，但强烈不建议。
