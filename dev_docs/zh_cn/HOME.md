# Tui Game 开发文档首页

## 前言

Tui Game 支持开发者制作额外的游戏与屏保包。为确保脚本运行稳定、开发过程顺利以及游戏正常游玩，程序对包的结构有严格要求，并提供了各类相关 API，同时对 Lua 语言原生内容进行了适当改造。
本文档汇总了所有官方提供的教学与查询文档。如在开发中遇到问题，均可在此处查找。
Tui Game 力求提供清晰的知识与信息。无论你是从未开发过游戏，还是从未接触过 Lua 语言，都能从文档中学到有用的内容。
