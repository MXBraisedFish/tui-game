# B9 IME 人工验收

## 用途

测试工具复用项目的 `TextInputService`、`CanvasService`、`FrameCompositor`、`FramePresenter` 和 `TerminalService`。它会持续刷新状态行，并允许同一输入框移动、显示覆盖层和响应终端 resize/focus 事件；每帧都把当前输入光标交给项目 presenter。

此工具验证 Windows Terminal 对项目帧尾光标更新的真实 IME 候选窗行为。它不替代宿主所有页面的逐页人工验收，也不记录用户输入内容。

## 启动

在 Windows Terminal 的一个交互式 tab 中，切换到目标 IME 后运行：

```powershell
cd E:\Code\tg-test\b9-ime-validation
.\run_b9_ime_lab.ps1
```

也可直接运行 `b9_ime_lab.exe`。请先在 Windows 设置中准备中文拼音输入法；日文测试时使用 Windows 可用的日文 IME。测试期间不要切换到其他终端模拟器。

程序输入框预填 `prefix-`，初始插入点在末尾。可以用左右方向键把插入点移到已有文字中间，再开始 IME 预输入。程序仅在屏幕上显示文本和提交/取消计数，不会写入文件。

| 按键 | 操作 |
|---|---|
| `Ctrl+Alt+Shift+P` | 在上、中、下三个页面位置间切换输入框 |
| `Ctrl+Alt+Shift+O` | 显示/隐藏覆盖层提示，输入框继续保持焦点 |
| `Ctrl+Alt+Shift+M` | 开启/停止自动滚动（每 700 ms 移动一行） |
| `Ctrl+Alt+Shift+L` | 清空输入文本和本地提交/取消计数 |
| `Ctrl+Alt+Shift+Q` | 退出并恢复终端；`F10` 也可退出 |
| `Enter` / `Esc` | 提交/取消；IME 可能先拦截按键以提交候选或取消预输入 |

## 测试矩阵

每组测试都先观察候选窗是否贴近正在编辑的插入点，再观察操作完成后文本和计数是否合理。请记录终端/IME 名称及复现步骤；不要为了测试关闭系统 IME。

| 场景 | 操作 | 记录 |
|---|---|---|
| 中文预输入 | 输入拼音但先不提交；用方向键或候选键改变候选 | 候选窗是否跟随当前插入点，有无跳到旧位置/屏幕边缘 |
| 中文提交与取消 | 分别提交一个候选，并在另一轮用 `Esc` 取消预输入 | 候选窗关闭后 caret 和输入内容是否正确 |
| 日文预输入 | 输入罗马音，切换/浏览候选，再提交和取消 | 同上；记录 IME 名称 |
| 光标在中间 | 将插入点移入 `prefix-` 中间后重复中文或日文预输入 | 候选窗是否锚定到中间 caret，而非字符串末尾 |
| 页面位置变化 | 预输入期间多次按 `Ctrl+Alt+Shift+P` | 候选窗是否跟随输入框位置变化，是否出现短暂脱锚 |
| 覆盖层刷新 | 预输入期间按 `Ctrl+Alt+Shift+O` 开关覆盖层，等待动态状态更新 | 候选窗是否仍在当前输入位置；文本是否意外改变 |
| 自动滚动 | 预输入期间按 `Ctrl+Alt+Shift+M`，观察数秒后再按一次停止 | 候选窗是否跟随每次输入行移动；是否跳动或冻结 |
| 窗口 resize | 预输入期间拖动/最大化 Windows Terminal 窗口 | resize 后候选窗和 caret 是否落在新坐标 |
| 窗口失焦/恢复 | 预输入期间切出终端再切回 | 失焦时表现；恢复后候选窗是否回到当前输入位置 |
| 终端恢复 | 按 `Ctrl+Alt+Shift+Q` 退出 | raw mode、alternate screen 与终端光标是否恢复 |

IME 可能在候选阶段消费 `Enter` / `Esc`，所以应用的计数器只表示按键最终到达文本输入组件的次数，不应作为 IME 已完成提交/取消的唯一证据。请以候选窗和屏幕上实际输入文本为准。
