# B8.5 终端闪烁观感复查

## 测试包

独立部署目录：`E:\Code\tg-test\b8-flicker-validation\`。双击 `run_b8_flicker_validation.cmd`，在主菜单的游戏列表选择 **B8.5 Flicker Review**。启动脚本从系统临时目录作为当前工作目录运行副本中的 `tg.exe`，用于同时复核生产路径以部署根为准。

包需要至少 95×26 的终端视口才能进入宿主 UI；视口更小时宿主会显示尺寸提示。画布本身随终端尺寸变化，并按可见区域裁剪，不要求为 160×50 或 240×80 改终端字体/缩放。

测试包提供四种画面：

1. `1` 静止参考：固定 ASCII、CJK 与彩色文本，用来观察不应变化的画面是否闪烁。
2. `2` 局部更新：只移动一个字符，观察小范围差分输出会不会带动其它区域闪烁。
3. `3` 全屏动态：大部分可见单元格每个呈现帧做平滑色带移动，是主要连续重绘场景。
4. `4` 低频脉冲：手动进入的 2 Hz 黑白高对比脉冲，用于直观看主观闪烁；再次按 `1`、`2` 或 `3` 可立即退出该模式。

`N` 顺序切换场景，`Space` 暂停/继续，`Esc` 返回游戏列表。程序隐藏终端光标。先以默认 60 FPS 观察；若要对照，可在主界面“设置 → 显示设置 → 游戏列表 FPS 上限”中依次选择 30、60、120。游戏包上限为 120 FPS，实际运行上限取宿主与包设置中的较小值。

## 观察项目

- 静止参考画面是否有意外闪烁、残留单元格或滚动。
- 局部更新时闪烁是否只发生在变化位置。
- 全屏动态画面是否出现明显卡顿、拖影、撕裂感或整屏闪烁；不同 FPS 下差异如何。
- 2 Hz 脉冲模式的表现与前三种场景的渲染伪影是否容易区分。
- 缩放 Windows Terminal 窗口后画布是否裁剪在可见区域、是否意外滚屏，退出时终端光标/画面是否恢复。
