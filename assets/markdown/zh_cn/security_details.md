# 安全详情

Lua 脚本只能调用项目开放的 API。访问范围取决于会话类型和包的“调试”设置。

## 游戏会话

- 文件 API 只能访问当前包的 `assets/` 目录，不能访问任意宿主路径或其他包的文件。
- `event.skip_action` 和 `event.clear_action` 仅供游戏会话使用。
- 屏保会话不会开放游戏控制 API。

## 屏保会话

- 屏保可以读取自己的包资源；不能写入文件、创建目录、删除文件或控制游戏动作。
- 宿主在投递前会过滤用户输入事件。

## 调试输出

包的“调试”设置控制 `debug.print`、`debug.info`、`debug.warn`、`debug.error` 和慢回调警告。关闭调试时，断言与受保护调用仍然可用。

Lua 脚本无法访问原生 `io`、`os` 或 `package` 库。宿主按会话限制内存和执行时间，并由宿主应用保留终端控制权。
